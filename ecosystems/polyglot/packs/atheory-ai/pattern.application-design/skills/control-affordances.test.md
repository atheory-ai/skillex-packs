# Tests: control-affordances.md

## Validation: Make available interactions discoverable

Prompt: A polished canvas exposes Delete only on hover and uses an unlabeled icon for Run. What makes those interactions discoverable?
Success criteria:
  - Provides identifiable action labels or unambiguous conventions and persistent or clearly reachable entry points.
  - Supplies touch and keyboard alternatives to hover and drag-only operations.
  - Defines meaningful control states without relying solely on tooltips, pointer cursors, or decoration.
