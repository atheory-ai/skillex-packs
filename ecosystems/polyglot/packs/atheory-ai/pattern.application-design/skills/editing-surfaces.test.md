# Tests: editing-surfaces.md

## Validation: Choose an editing surface by context and interruption

Prompt: A builder puts every settings form in a modal because the component library provides one. How should it choose editing surfaces instead?
Success criteria:
  - Weighs task context, frequency, complexity, and intentional interruption across inline, inspector, dialog, and destination choices.
  - Does not derive save or cancellation semantics merely from the chosen container.
  - Defines the subject, entry and return path, and space for errors and keyboard-visible layouts.
