# Tests: visual-hierarchy.md

## Validation: Make task priority visible

Prompt: An editor renders every panel title, status badge, Run button, and Apply button with the same strong emphasis. How should its hierarchy change?
Success criteria:
  - Groups and prioritizes information according to the current task and subject.
  - Distinguishes document and local actions through scope and placement rather than one globally dominant button.
  - Uses spacing, alignment, and text roles without depending only on color or decorative heading sizes.
